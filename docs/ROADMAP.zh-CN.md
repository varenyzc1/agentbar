# AgentBar 后续功能规划

更新日期：2026-09-11。已对齐上游 `1031687`；以下为在现有功能基础上的建议增量。

## 本次：账号套餐标签

- Codex 卡片标题旁显示独立胶囊标签，复用应用配色，支持浅色和深色模式。
- 使用配额快照的 `plan_type`，例如 `plus` → `Plus`、`pro` → `Pro`。
- 显式带倍率的值可格式化为 `Pro 5x`；这是显示兼容能力，不代表接口一定返回该值。
- 无套餐字段时隐藏标签；未知类型保留可读名称。仅有 `pro` 时不推断倍率。
- 标签跟随现有缓存和刷新流程，不新增认证读取或网络请求。

套餐参考：[OpenAI 官方价格与配额说明](https://learn.chatgpt.com/docs/pricing)列出 Pro 5x 和 Pro 20x；该页面未提供 `plan_type` 到倍率的接口映射，当前不做别名推断。

## 建议实施顺序

| 优先级 | 功能 | 用户价值与范围 | 验收标准 |
| --- | --- | --- | --- |
| P1 | 配额和预算通知 | 在现有配额阈值、月预算基础上增加可选 macOS 通知；支持重置提醒 | 用户主动启用；同一窗口同一阈值只提醒一次；过期缓存不触发；账号切换不串通知 |
| P1 | 卡片显示管理完善 | 现有模块隐藏和排序已实现；可进一步增加自动隐藏未配置来源、折叠重置卡区域 | 保留手动显示选择；隐藏后可恢复；中英文、浅深色布局一致 |
| P1 | 套餐倍率识别完善 | 调研是否有稳定、可验证的细分套餐字段；若没有，可提供明确标为手动的本地备注 | 不把 Pro 自动等同于某个倍率；手动信息不冒充接口识别结果；账号切换不串标签 |
| P2 | 配额消耗趋势 | 本地保存精简配额采样，显示最近窗口消耗速度及预计耗尽时间 | 区分重置和账号切换；样本不足时不预测；预测标明估算；不存原始响应或凭据 |
| P2 | 用量明细与项目筛选 | 在现有模型排行和来源汇总基础上增加完整明细与项目筛选，定位主要 token 和费用来源 | 合计与当前摘要一致；缺失项目有归属；大数据量查询不阻塞 UI |
| P2 | 月预算进度 | 展示本月预算使用率、按当前速度估算的月底支出 | 继续明确费用为估算；未设置预算有合理空态；跨月、时区边界正确 |
| P3 | 本地 CSV 导出 | 按时间范围导出日汇总、来源或模型汇总，用于个人复盘 | 用户选择保存位置；默认不含账号和原始日志；正确处理引号、换行及公式注入 |

## 开发安排

1. 先做通知并完善现有卡片显示管理，让每天打开菜单栏更有用、更紧凑。
2. 再引入配额历史采样；稳定后增加预测，避免直接用瞬时百分比猜测剩余时间。
3. 最后做明细分析和导出，复用现有 SQLite 与聚合逻辑。

每项分别交付。涉及设置、数据库、配额与聚合时补充聚焦测试；UI 改动运行 release 构建，并检查紧凑面板、中英文和深浅色布局。
